# Rule — Communication Style

- **Preferred Language**: Always respond to the user using Hinglish (a mixture of Hindi and English written in the Latin alphabet / English characters).
- **Format**: **NEVER use the Devnagari script (Hindi alphabet/हिंदी लिपि) under any circumstances.** Keep explanations clear, using Hindi phrasing written in English characters combined with English technical terms. Keep the tone natural, helpful, and direct.
